# OMP Suite — Seamless Built-In Behavior

All `omp-suite` capabilities (`omp-suite_core`) should work **automatically and transparently** during normal coding requests—the user should never have to invoke `/omp-*` commands manually to get Oh My Pi behavior:

1. **Hashline Edits by Default (`hashline_read` / `hashline_edit`)**: For medium/large files or multi-line refactors where whitespace or repeated lines could cause string-match retries, use `hashline_read` and patch atomically with `hashline_edit` (`line:hash` anchors).
2. **Staged Structural Codemods (`ast_grep` / `ast_edit` / `ast_resolve` / `ast_reject`)**: Whenever performing cross-file pattern searches or structural rewrites (e.g., migrating calls, renaming patterns), use `ast_grep` and stage previews with `ast_edit`, verify the diff, and apply atomically with `ast_resolve`.
3. **LSP & Automatic Diagnostics (`lsp_query` / `lsp_diagnostics`)**: Use `lsp_query` for definitions, references, hover types, and symbol lookups, and address any post-edit diagnostics surfaced by `omp-suite` hooks before finishing.
4. **Real Debugging over Print Statements (`dap_launch` / `dap_command` / `dap_inspect`)**: When diagnosing runtime logic bugs in Python, C/C++/Rust, or Go, launch a real DAP session to inspect frames, locals, and evaluated expressions instead of sprinkling temporary print statements.
5. **Persistent Eval & Notebooks (`eval_run` / `notebook_*`)**: Use stateful `eval_run` kernels for calculations, data exploration, and quick reproduction scripts, and `notebook_*` tools for `.ipynb` files.
6. **Automatic Curated Memory (`memory_retain` / `memory_recall` / `memory_reflect` / `memory_learn`)**: Proactively call `memory_recall` when entering an unfamiliar area and `memory_retain` whenever you uncover a durable project convention, architectural invariant, or non-obvious pitfall.
7. **Virtual URIs & Conflict Resolution (`vread` / `vwrite` / `conflict_resolve`)**: Use `vread` naturally for `pr://<n>`, `issue://<n>`, `conflict://`, `sqlite://`, `archive://`, and web URLs, and resolve merge conflicts cleanly via `conflict_resolve`.
8. **Zero-Tax TTSR Guardrails & Advisor Watchdog**: If a `PreToolUse` TTSR hook blocks an action with `⚠ TTSR Injecting rule: <name>`, immediately correct the approach. Use `omp-advisor` / `advisor_note` on risky changes to catch missed acceptance criteria.
9. **Native UI — Do Not Spam Chat with ASCII HUD Dumps**: In `agy` CLI, the live OMP v19 / Tern statusline and activity tray are rendered **natively in the terminal chrome** via `statusLine`. Never print ASCII HUD boxes in chat unless the user explicitly asks for a text dump; only call `omp_hud` when opening the interactive MCP App dashboard in the Antigravity App or when explicitly requested.
